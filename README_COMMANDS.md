# Команды для уведомлений и отчетов

## Настройка

### 1. Настройка Mailer

Добавьте в файл `.env` следующую переменную для работы с MailHog:

```env
MAILER_DSN=smtp://mailhog:1025
```

### 2. Настройка email для отчетов

В файле `config/services.yaml` уже добавлен параметр:

```yaml
parameters:
    app.report_email: 'admin@study-on.local'
```

Вы можете изменить email получателя отчетов на нужный.

## Команды

### Уведомление об окончании срока аренды

Отправляет письма пользователям, срок арендованных курсов у которых заканчивается завтра.

```bash
docker-compose exec php bin/console payment:ending:notification
```

**Что делает команда:**
- Ищет транзакции с арендованными курсами, срок которых истекает завтра
- Группирует их по пользователям
- Отправляет каждому пользователю письмо со списком истекающих курсов
- Использует шаблон `templates/email/expiring_courses.html.twig`

**Формат уведомления:**
```
Уважаемый клиент! У вас есть курсы, срок аренды которых подходит к концу:
[Название курса] действует до [дата и время].
```

### Отчет по оплатам за месяц

Генерирует отчет по данным об оплаченных курсах за предыдущий месяц и отправляет на email, указанный в конфиге.

```bash
docker-compose exec php bin/console payment:report
```

**Что делает команда:**
- Генерирует отчет по оплаченным курсам за предыдущий месяц
- Группирует данные по курсам и типам оплаты (аренда/покупка)
- Считает общую сумму
- Отправляет отчет на email из параметра `app.report_email`
- Использует шаблон `templates/email/payment_report.html.twig`

**Формат отчета:**
```
Отчет об оплаченных курсах за период ДД.ММ.ГГГГ - ДД.ММ.ГГГГ

Таблица с колонками:
- Название курса
- Тип курса
- Число аренд/покупок
- Общая сумма

Итого: XXX руб.
```

## Автоматизация

Для автоматического запуска команд добавьте их в cron:

```bash
# Уведомления каждый день в 9:00
0 9 * * * docker-compose exec php bin/console payment:ending:notification

# Отчет первого числа каждого месяца в 10:00
0 10 1 * * docker-compose exec php bin/console payment:report
```

## Структура шаблонов

### Базовый шаблон email

`templates/email.html.twig` - базовый шаблон со стилями Study-on для всех email сообщений.

### Шаблон уведомлений

`templates/email/expiring_courses.html.twig` - шаблон для уведомлений об истекающих арендах.

### Шаблон отчета

`templates/email/payment_report.html.twig` - шаблон для месячного отчета по оплатам.

## Тестирование

Для тестирования отправки писем используется MailHog:
- Веб-интерфейс: http://localhost:8025
- SMTP: localhost:1025

Все отправленные письма будут видны в веб-интерфейсе MailHog.
