# Тестирование команд уведомлений и отчетов

## Подготовка к тестированию

1. **Добавьте переменную окружения** в файл `.env`:
   ```env
   MAILER_DSN=smtp://mailhog:1025
   ```

2. **Запустите сервисы**:
   ```bash
   docker-compose up -d
   ```

3. **Загрузите тестовые данные**:
   ```bash
   docker-compose exec php bin/console doctrine:fixtures:load --append
   ```

## Тестирование команд

### 1. Тестирование уведомлений об истекающих арендах

```bash
docker-compose exec php bin/console payment:ending:notification
```

**Ожидаемый результат:**
- Команда найдет пользователей с истекающими завтра арендами
- Отправит им уведомления на email
- В консоли покажет количество отправленных уведомлений

### 2. Тестирование отчета по оплатам

```bash
docker-compose exec php bin/console payment:report
```

**Ожидаемый результат:**
- Команда сгенерирует отчет за предыдущий месяц
- Отправит отчет на email из настроек (admin@study-on.local)
- В консоли покажет период отчета

### 3. Проверка отправленных писем

Откройте веб-интерфейс MailHog: http://localhost:8025

Вы увидите все отправленные письма с:
- Уведомлениями пользователям об истекающих арендах
- Отчетом администратору

## Отладка

Если команды не работают:

1. **Проверьте статус сервисов**:
   ```bash
   docker-compose ps
   ```

2. **Проверьте логи PHP**:
   ```bash
   docker-compose logs php
   ```

3. **Проверьте логи MailHog**:
   ```bash
   docker-compose logs mailhog
   ```

4. **Проверьте список команд**:
   ```bash
   docker-compose exec php bin/console list | grep payment
   ```
